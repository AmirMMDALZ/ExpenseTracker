# Expense Tracker
- This Program Tracks Your Daily Expenses
## In This App You Can:
- Add Expenses
- Show Expenses
- Show Total
- Save Expenses in a file
- Load previous Expenses from file

note:The expenses are saved in a file named "expenses.txt"

## Setup Guide:
1. Clone this repository (or download it as ZIP)
2. Open the .sln file in Visual Studio
3. Press F5
